# Final corrective amendment

This amendment was chosen **after all six original outcomes were sealed**.
The original protocol planned no expansion. The main chat and Astra deliberately
changed that stopping plan after every owner preserved the consequential error:
using the experimental 15% gate to justify retiring useful progress without
reconciling earlier user priorities. This is exploratory remediation, not a
preregistered extension or a favorable replacement for those six results.

Exactly four fresh Luna/high owners receive the same packet and twelve-call,
ten-minute limits. Two receive the existing baseline plus a short general cue
about the source and scope of decision criteria. Two receive the existing baseline
plus the actual next historical user correction, as **assisted positive controls**.
They are fresh continuations, not repairs of the earlier owners. No helper support
is used in this phase; this is not another parallelism comparison.

All four use the original four separate assessment dimensions. The criterion cue
contains no CPU count, percentage, configuration name or pipeline solution. It
was nevertheless designed with knowledge of this failure and is not held-out
validation. The actual user correction adds task-specific information to its
control, so it is not an equal-information prompt comparison.

Preserve the failed experimental gate and legitimate deployment/provenance limits.
The relevant distinction is whether a gate failure alone establishes that useful
work should be discarded or that the user's outcome is adequately served.
Record executed work, counterevidence, unsupported conclusions and budget use.
An independent reviewer will grade outputs without the arm map or instructions.

There will be **no further prompt tuning, cases or participant repairs** after
these four. Mixed or failed outcomes remain results. Any kit change must be
reported as a semantic clarification with limited behavioral evidence, not a
demonstrated general cure for agent stagnation. No receiver or global-kit changes
are authorized by this amendment.
