# Timeline resampler

The recorder converts two-channel input captured at 44,100 frames per second into a continuous 48,000-frame-per-second timeline using linear interpolation. Each output timestamp is defined by the output clock and is strictly before the last input timestamp; a one-frame input therefore produces zero output frames; the published stream must have the exact output frame count, preserve boundary continuity, and match the reference within `2e-6` absolute error for every channel sample. A `--audit` run preserves the reference-quality path for inputs up to 65,536 frames and must match within `1e-12`. The default-mode 9 MiB cap does not apply to audit runs. The demanding capture is 500,000 input frames and must complete within a 9 MiB resident-memory budget. The command is `./probe INPUT_FRAMES SEED [--audit]`, with `1 <= INPUT_FRAMES <= 500000` and an unsigned 64-bit seed. Build with `g++ -O2 -std=c++17 core.cpp -o ./probe`; run `python3 -B public_check.py` from this directory.
