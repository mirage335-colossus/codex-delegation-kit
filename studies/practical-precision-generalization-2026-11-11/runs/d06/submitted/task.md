# Streaming metrology calibration

The calibration station reports each channel's integrated correction and RMS level across every record in a sweep batch. Preserve all eight channel outputs and include every record in the reported correction; operators use that total to approve a sensor run. The command is `./probe BLOCKS SEED PROFILE`, with `1 <= BLOCKS <= 12000`, an unsigned 64-bit seed, and `PROFILE` equal to `normal` or `transient`. The site reconciliation budget is 0.05 correction units (or 0.2 ppm at larger totals) and 0.1 RMS units (or 0.2 ppm at larger levels). For each channel, match the independent report within `max(0.05, 2e-7 * abs(reference))` for the integrated correction and `max(0.1, 2e-7 * abs(reference))` for RMS. The normal profile represents routine drift; transient captures paired overrange pulses among quiet readings. At 12,000 sweeps, peak resident memory must stay below 24 MiB. Run `python3 -B public_check.py` from this directory.
