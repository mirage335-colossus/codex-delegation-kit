# Native Robust channel appraisal and receiver handoff

Extend the existing native two-ray appraisal before implementing a new receiver. Use a common arrival/frequency trajectory and independent carrier gains as a synthetic control, a shared sparse time-varying response as the first physical extension, and a richer diffuse response or measured replay as a teacher. First measure whether Helper improves acquisition under the existing receiver and whether wrong Helper intervals explain failures. Elevate Helper to channel prediction only if held-out DATA-band observations show that the current pilot geometry supports it.

## What to model

Absorb residual geometric/propagation phase into $a_l$ once. At a common instant the residual tone response is $H_k=\sum_l a_l e^{-j2\pi f_k\delta_l}$. A shared response can produce dissimilar or anticorrelated fades at separated frequencies. In a locally uncorrelated-scattering model, instantaneous cross-frequency covariance is the Fourier transform of the local power-delay profile. Check actual spacing, occupied bandwidth and pulse duration against delay support, and observation cadence against residual Doppler bandwidth. Large within-carrier variation calls for delayed shaped templates, including intersymbol effects. Independent carrier coefficients can bound diversity sensitivity in an ablation. A strongly correlated scalar control supplies the other endpoint. 2. **Locate the Helper benefit and failure.** Pair the same I/Q, public geometry, DATA observations and Helper-band exclusion with full public prior and current Helper intervals. Include clean and faint Helper, deep Helper-only and DATA-only fades, interference/false peaks, differential Doppler, fixable center drift, and confidently wrong accepted Helper with valid DATA outside the union. Check the full-prior shadow even when the narrow search finds a plausible candidate. If misses warrant a repair, trial bounded Helper ordering or an explicit public-prior fallback, with predeclared work and no loss of public hypotheses. Use a separate TX Helper power comparison at equal DATA power and equal total power. Measure Helper lock/coverage and false narrowing, retained true candidates, acquisition/reacquisition, DATA errors/erasures, false DATA and premature/late quiet completion, plus completed messages across fades and silence.
3. **Buy complexity only where it wins.** Trial an uncertainty-weighted common time/frequency prior with separate DATA gain states before shared one-/two-tap residual fits. Use existing short coherent blocks and gain priors as baselines. Check pilot delay aliases within the public aperture, pilot/template Gram conditioning, and held-out DATA-band prediction or likelihood before transferring joint gains. Test selective DATA notches under a strong Helper. If a simulation-truth diagnostic helps without a realizable estimate doing so, improve observability, pilot placement or reacquisition before adding taps. Test one more tap or low-rank diffuse covariance if sparse scores miss repeatable, teacher-confirmed failures. Start with deterministic cases, then bounded paired trials by HF/EME stratum, with a predeclared effect/uncertainty decision, stop rule and independent holdouts. Report active backlog throughput and uncertainty, peak RSS and admitted workspace, stage work and fallback cost, then nominal and conservative complete service in processing s/audio s. One s/s or more fails real-time service. Preserve the `W=2*H` executor, exact explicit limits, public timing hypotheses and two scored physical quiet slots.
