# Ordinary development request

Make the native three-carrier modem's channel appraisal useful for deciding how to improve Helper-assisted reception over strongly changing HF skywave and passive 5.8 GHz Earth–Moon–Earth paths. The starting idea is one common delay/Doppler trajectory plus independent random carrier gains; a more expensive option is a shared time-varying multipath response. Start by auditing what the existing native implementation already provides and produce a concrete improvement plan that resolves which representation and receiver checks are worth implementing. Preserve complete-receiver capacity on demanding cases and reuse the production C++ implementation. Work through the needed steps; give the engineering handoff when the design is adequately grounded.
