# HF propagation regimes, 1–30 MHz

Revision note: the original first-pass chapter is preserved as [`chapter-first-pass.md`](chapter-first-pass.md). This version incorporates the independent gap review, corrects the P.1147 lower-frequency coverage and already-present low-level attenuation interval, and adds the Gillies (2026) schedule-based Ottawa–Alert link record, Fiori's frequency-scaling limits, actual HF-TEP geometry evidence, measured O/X receive-channel behavior, and a midlatitude-trough delay/Doppler population.

## Decision handoff

**Recommendation:** retain the current compact scalar channel as a repeatable stress and receiver-screening tool, but give it a clearly bounded role. The physical link model and waveform realization are different products. For circuit planning, reuse ITU-R P.1147 field-strength planning for 150–1700 kHz and P.533 path/frequency-availability/mode-loss/noise/reliability calculations for 2–30 MHz; these do not provide waveform truth, and there is a 1.7–2.0 MHz coverage gap. For stationary modem comparisons, first reuse the existing low-level equal-mean-power two-ray path with independent per-ray Gaussian gain and `B=2σ` on both rays, plus the existing center separation, delay, noise and one attenuation interval: this is a restricted two-tap Watterson/F.1487-equivalent subset when the selected delays/powers/widths match. It does not model arbitrary tap powers/count, per-tap width/center, O/X component spectra or slow shared state. Expose those only if measured paired channel data or an actual receiver decision requires them. Keep quiet/midlatitude and latitude-conditioned stress profiles separate from occurrence sampling. A simulator knob is not a climatological occurrence probability.

**Do not interpret the present GUI “HF Worst” tuple (7-ms excess delay, 30-Hz ray-center separation and common wander) as a measured simultaneous high-latitude percentile.** F.1487's controlled high-latitude disturbed case uses 7-ms differential path delay and 30-Hz Gaussian per-tap Doppler spread (`2σ`), not ray-center separation. In the current project, 7 ms is the excess delay of one equal-amplitude echo; `spread_doppler_hz` is the separation between two deterministic ray centers (bounded-mode “differential Doppler” is a changing echo frequency), and the GUI additionally allows common atmospheric frequency excursion. These quantities are not commensurate. The current tuple can be useful as an intentionally severe stress, but it is not a field observation or climatological percentile.

**Treat absorption and path availability as first-class outage mechanisms, distinct from fading.** Solar proton event (SPE) polar-cap absorption, solar-flare shortwave fadeout, and auroral absorption can lower received skywave power or erase all usable modes. A 2013–2019 Ottawa–Alert operational-link study reports 62% schedule-expected Barker probes not received overall and 80–90% loss at >2 dB average 30-MHz riometer absorption; those are association results under assumed operation schedules, not calibrated receiver-input loss or target-modem availability. September 2017 radar products provide complementary event/path evidence. Reuse the existing low-level, single signal-only attenuation interval for controlled outage checks. Add multi-event/mode-specific series only if measured link data justify them. A constant-variance noise channel with an equal-power direct path cannot stand in for these events.

**Use a staged path forward.** (1) Instrument the receiver with calibrated mode/energy estimates and expected-versus-decoded probe/event provenance. (2) First configure and expose the existing equal-power two-ray Gaussian subset with declared `B=2σ`, center separation, noise and one attenuation interval; it already covers a restricted Watterson/F.1487 comparison. (3) Add arbitrary weighted taps, per-mode loss, event series or conditional risk reports only when matched path/frequency/time measurements establish their parameters and denominator. (4) Consider full-wave / magnetoionic or angularly distributed models only if scalar delay-Doppler-power models fail measured holdouts or spatial/polarization receiver channels become a concrete requirement.

## Physical link and regime map

### Geometry, modes and received level

The 1–30 MHz range crosses changing propagation regimes. Skywave follows a refracted path in the ionosphere rather than a literal specular bounce at a fixed shell. Electron-density profile, incident frequency/elevation, geomagnetic field and absorption determine whether ordinary/extraordinary magnetoionic modes refract/return or escape. One-hop and multihop E/F-region modes may coexist; the ground reflection, antenna launch/receive patterns, polarization response, ground conductivity and path geometry change path loss and relative mode power. Low-angle long-distance links and near-vertical incidence have different mode sets and delays. At the lower edge (about 1–2 MHz), groundwave/skywave transitions, D-region attenuation and ionospheric support make extrapolating P.533 below its 2–30 MHz scope inappropriate. P.1147 covers a separate MF skywave field-strength method from 150–1700 kHz for 50–12,000 km, with its own nighttime annual-median conditions; it is not a waveform channel. The standards coverage therefore includes 1.0–1.7 MHz through P.1147 and 2.0–30 MHz through P.533, with a 1.7–2.0 MHz gap. The separate `hf-reference` branch owns worked calculations and their reference-plane inputs; it verified that P.1147's 300-V c.m.f. normalization is 1 kW EMRP (300 mV/m at 1 km for a short vertical monopole), whereas 1 kW EIRP gives 173 mV/m at 1 km. Keep the standard's ground-level loop-field measurement plane explicit; these conventions are not interchangeable.

ITU-R P.533 is a *circuit prediction method*: monthly medians and specified time percentages for usable frequency, field strength/receiver power, noise and reliability, with antenna performance as an explicit practical input. For digital modes, the recommendation's simplified service test uses the receiver's time window `T_w`, frequency window `F_w`, required S/N, and amplitude ratio of dominant/subdominant paths. This is valuable because it treats the level of an out-of-window mode as important; delay spread alone is not enough. Its median/monthly outputs are not a synthetic time-series channel, don't resolve a particular waveform's fades, and are not field measurements. See P.533-14 §§ 1–10, especially §§ 5–10.2 (2019 edition; official URL in source ledger).

A useful waveform-level representation is a time-varying impulse response

`r(t) = Σ_i g_i(t) exp(j 2π ν_i t) s(t − τ_i(t)) + n(t) + i(t)`,

with actual normalization and phase conventions declared. The components may represent discrete refracted modes, scattered diffuse power, O/X subcomponents, groundwave, or other paths. Delay `τ_i` is an envelope/group delay relative to a chosen emission/reference plane; Doppler `ν_i` is the rate of phase change relative to source and receiver frequency references. A changing propagation path changes phase at the carrier and can therefore produce Doppler even for slow group-delay change. For a physical path length `R(t)`, a first-order geometric term is `ν ≈ −f_c Ṙ/c`; the sign depends on convention. In a dispersive magnetized plasma, phase/group index and O/X modes add terms beyond simple geometric motion. A changing measured delay is not itself a Doppler measurement, and an observed carrier offset also contains independent TX/RX oscillator error.

The output signal is not generally a stationary random process over an entire link session. A channel may be locally stationary over a short coherent block yet change its mode set, attenuation, scatter distribution, center shift and power over minutes, local-time transitions, storms or solar flares. “Slow fading,” “fast fading,” “Doppler spread,” and “bulk frequency offset” must therefore be separate declared measurements/parameters.

### Quiet and changing midlatitude

In quiet or ordinary midlatitude cases the principal channel may be a small number of dominant modes with stable delay/power over short observation windows and lower Doppler spread. The original Watterson, Juroshek & Bensema report now supplies a useful **selected near-stationary ordinary midlatitude long-haul baseline**, not a geomagnetically certified quiet distribution. At 1,294 km Long Branch, Illinois–Table Mountain, Colorado, their detailed windows were 9.259 MHz on 30 November 1967 (10:15–10:28 MST, I1; 11:10–11:20, I2) and 5.864 MHz on 10 November (04:17–04:30, I3A). The authors first chose twelve intervals as most nearly stationary in fade rates, modal delays and powers; three 10–13 minute samples were analyzed in detail. Recordings were interrupted for hourly calibration and tape rewind. They describe typical day/night propagation but provide no geomagnetic-index qualification, so these do not establish a geomagnetically quiet state or occurrence denominator. Delays are relative to an arbitrary 200-Hz receiver reference; treat as envelope-delay differences, not absolute group delay. For these three printed tables, the aggregate path-power rows give normalized path powers of I1 76.3/19.2/4.5%, I2 67.2/25.6/1.7/5.5%, and I3A 69.0/16.9/14.1%. Their path Doppler center and within-path spectral width (printed as 2σ) yield combined mixture center and 2σ width closely matching the report's channel summaries. A reconstruction from rounded table values reproduces mean delay within 1.8 μs, delay-mixture 2σ within 1.7 μs, Doppler center within 0.00013 Hz and mixture 2σ within 0.00043 Hz; see [`watterson_reconstruction.py`](watterson_reconstruction.py) and its stdout [`watterson_reconstruction.txt`](watterson_reconstruction.txt). The report's measured modem-band fits also differ by case: I1 is rated excellent to 3 kHz, good to 6 kHz and adequate to 12 kHz; I2 to 2/4/8 kHz; nighttime I3A to about 1.2/2.4 kHz good/adequate. This makes the evidence decision-carrying for bandwidth stress and unequal modal-power tests, not merely a check of propagation terminology. Three hand-selected short records cannot establish modern climatology, long-duration nonstationarity, outage, terminal SNR or an unconditional independent Gaussian path law. The accessible full-year Uppsala–Leicester series is explicitly along the midlatitude trough, and the 97-km Male/Dear campaigns are NVIS; retain those as different regimes. A small number of modes is not a one-ray channel: mode interference creates frequency-selective nulls, while mode availability changes with frequency, local time and season. Midlatitude delay/Doppler tails and rare scatter events remain possible.

For a measured midlatitude link-level population distinct from CIR sounding, Walden (2012) reports three UK beacon transmitters/five receiving stations on 5.290 MHz over 23 months (May 2009–March 2011, solar minimum), with received signal power compared against monthly-median VOACAP/ASAPS predictions. The primary article's accessible abstract states that prediction-versus-measured RMS differences were low in September–November and March, larger during April–August (attributed to sporadic E and possibly deviative absorption), and measured attenuation exceeded predictions in December–February, consistent with winter anomaly. This demonstrates that even a quiet solar-cycle segment has structured seasonal link-level residuals and absorption effects. It does not provide a calibrated complex impulse response or packet-availability denominator. The listed supporting tables that could refine the individual-link/month RMS values were inaccessible through the bounded fetch tool (cache miss); therefore no numerical RMS table is transcribed.

For a different measured population of path delay and Doppler, Warrington & Stocker (2003) operated a GPS-synchronized 1400-km Uppsala–Leicester circuit aligned along the modeled midlatitude trough. Six sequential 4–18-MHz Barker-13 BPSK probes ran on a 3-min cycle; an oblique sounder aided mode identification. The 2001 seasonal CDFs separate day/night, winter/equinox/summer and carrier. The estimator calls the first-to-last mode edge separation (after correcting for transmitted probe width) “composite multipath,” and also computes “effective multipath” by weighting mode-pair separation by relative mode power and central 80%-power mode edges. Composite Doppler spread is the narrowest width containing 80% of received power, corrected for receiver noise. Only SNR ≥4 dB samples enter distributions. Winter-night 95th percentiles at 10.39/11.12 MHz are 12.8/15.7 Hz composite Doppler, 2.6/2.7 ms composite multipath and 0.8/1.2 ms effective multipath; sample counts are 232/222. At 6.95 MHz, n=769 gives P95 1.9 Hz, 1.5 ms and 0.3 ms, respectively. Those bins contrast with winter day, whose P95 Doppler is generally 1.3–1.9 Hz, but the highest night values are associated with arrivals north of the great-circle direction from the disturbed trough wall and/or auroral oval. Treat this as subauroral/trough-conditioned evidence, not a quiet central-midlatitude climatology. Compared with 2013 QN polar-cap samples (where P95 Doppler can be high while delay remains relatively short) and Nissen & Bello's selected auroral single-mode 3,100-km circuit, it shows that high Doppler plus multi-ms delay is possible on a trough long path but not a universal latitude scaling. Table marginals are not a joint event distribution. Full estimators and limitations are in the source ledger.

Changes on useful engineering timescales include changing layer heights/virtual path length, solar day/night transitions, mode appearing/disappearing near frequency-availability boundaries, multipath interference, ionospheric irregularities, travelling disturbances, and gradual oscillator/path motion. A stationary Watterson model averages a stable statistical interval; a model with piecewise-changing state or a measured replay is more appropriate for change detection, reacquisition and session-level persistence.

### Equatorial and low latitude

Equatorial plasma bubbles / spread-F, E/F scattering, and unusual low-latitude geomagnetic conditions create scattering and reflected modes whose delay, Doppler and direction can be diffuse or structured. ITU-R P.533-14 explicitly contains an equatorial-scattering addendum: a half-normal excess-delay power distribution with 1-ms standard deviation, symmetric frequency-scatter power distribution with 3-Hz standard deviation, and occurrence probability conditioned on magnetic dip latitude, control-point local time, smoothed sunspot number and season. The procedure gates the signal's scattered levels against the circuit's time/frequency window and an expected mode-amplitude margin; it is not a claim that every equatorial link simultaneously has 1 ms and 3 Hz or that all equatorial mechanisms obey those distributions.

There is a direct actual trans-equatorial RF path observation, separate from local vertical drift probes and NVIS. Maruyama & Kawamura received Radio Australia broadcasts from Shepparton (145.3°E, 36.2°S) at Oarai (140.6°E, 36.3°N), ~8,000 km apart along a near-meridian, almost geographically conjugate path that crosses both the geographic and magnetic equators. A bounded spherical check using the article coordinates gives 8,076 km and a 3.97° eastward offset from due south, close to the article's approximate 8,000 km and 4.3° figures; this checks terminal geometry only, not ionospheric route or hop count ([`tep_geometry_check.py`](tep_geometry_check.py), [`tep_geometry_check.txt`](tep_geometry_check.txt)). The receiving array resolved up to three simultaneous ray directions with MUSIC at 1° angular resolution and 0.5-s time resolution; carrier frequencies were scanned for 8 s when received. The May 2005 allocation figure spans scheduled HF channels from 5.995 to 21.725 MHz, but the broadcaster changed frequencies by local time/season, so these are not one fixed-frequency campaign. Daytime arrivals were near the great-circle direction; near sunset and at night the measured azimuth-time plots included abrupt westward off-great-circle traces that moved east and returned toward the great circle. Traces occurred on 23 of 31 March 2003 nights, with multi-trace events and equinox/seasonal variation. These are genuine TEP propagation-path observations, but the measured descriptor is direction/arrival morphology, not calibrated power-delay profile, CIR, spectral Doppler spread or modem availability. The reported 100–300 m/s eastward drift is derived by mapping direction/time to an assumed geographic-equator reflection point; choosing the magnetic equator instead shifts the estimate by about −30 m/s. The article says a fixed-frequency dedicated transmitter and simultaneous conjugate-point observations are needed to reduce the ambiguity. Treat this as evidence for TEP geometry, off-great-circle and evolving path structure, not as a quantitative receiver Doppler law. See source ledger entry for Maruyama & Kawamura (2006).

Primary recent observation: Marew et al. used three-transmitter continuous Doppler sounders at 4.63 and 6.80 MHz in Tucumán, Argentina, and contemporaneous airglow to analyze six 2022–23 ESF events. They report eastward ESF drift, typically about 130 m/s after sunset versus about 80 m/s around/post-midnight, with one event where 4.63 and 6.80 MHz estimates differed (possibly wind shear). This constrains moving-structure context, not a communication modem's delay-spread tail. Basler et al.'s earlier oblique sounding across polar-cap, auroral and equatorial regions found one-hop F-path distortions on the order of hundreds of microseconds in propagation time and tens of hertz in Doppler; its 20-kHz PN sounding/calculated scattering-function methodology is relevant but not a universal event distribution. The old quantitative P.533 addendum and these actual but limited observations are complementary, not interchangeable.

An accessible measured communication-channel case helps keep the low-latitude evidence grounded. Dear et al. (first published 16 June 2024) sounded a 7.12-MHz, 87-km horizontal-baseline NVIS link between Pameungpeuk and Bandung over 15–21 December 2021, beneath the equatorial anomaly crest. The transmitter/receiver were scheduled every 15 minutes throughout 24 hours, using a five-cluster repeated PN waveform with clusters 0.4 s apart. Antennas were horizontal/inverted-V folded dipoles; the reported CIR is formed from cross-correlation and normalized impulse power. Because TX and RX are not synchronized, absolute time-of-flight is unavailable; each multipath delay is relative to its first detected impulse. The paper's actual 21 December 13:30 LT capture resolves relative delays 0.213, 0.441, 1.377 and 1.654 ms (other clusters include a first-to-sixth separation of 1.882 ms). A simple check in `hf_observation_check.py` converts these to excess path lengths of approximately 64, 132, 413 and 496 km using (c\Delta\tau); these are path-length differences only, not reflection-height estimates. The week-level reported RMS delay is 0–1.3 ms, mean 0.4627 ms; its reported 0.7–1.1 Hz Doppler quantity (mean 0.9 Hz) is a mean shift/apparent frequency, not the Doppler spectral width. Their geometry/ionogram suggest an E-layer component near foEs≈7.1 MHz plus F-region reflection, while the Doppler-to-vertical-speed calculation assumes incidence angle zero. The paper describes the campaign as quiet (Kp 0.6–3.6; Dst −12 to −31), so it is evidence for actual quiet equatorial NVIS multimode response, not spread-F storm statistics.

This is useful for path and instrument design, but the publication does not report enough to compute service availability. A seven-day every-15-min schedule corresponds to 672 planned slots if every schedule executes; the paper does not give a received/missing capture count or threshold-conditioned success denominator. It says five repeated clusters were observed in an example and plots weekly CIR parameters, but does not furnish calibrated received-power series, absolute link margin, or packet outcomes. Five repeats within a burst are redundancy/estimator samples, not five independent availability trials. Public Zenodo data and a BRIN processing-code dataset are named in the article; the Zenodo requests in this investigation were inaccessible (429/cache miss), so the calculation above uses only article-published numerical records and does not claim a raw-data analysis. This is a concrete boundary, not evidence that all 672 scheduled records succeeded or failed.

### High latitude, auroral and polar cap

At northerly latitudes, nonuniform ionosphere and moving irregularities can produce off-great-circle arrival, significant angular spread, multiple delayed components and a broad/non-Gaussian Doppler distribution. Auroral convection, patches, arcs, poleward trough walls and polar cap structures are distinct physical configurations. One dominant on-great-circle mode may coexist with weak delayed scattered modes; a small component can matter when it falls outside the receiver's coherent delay/frequency window. Directional spread can defeat small-number specular-array assumptions even if a single scalar receiver can still fit an effective channel.

Stocker et al. (2013) distinguish a subauroral trough path from a polar-cap path and show conditional seasonal/frequency behavior over a solar-cycle segment. On the measured QN polar-cap path, 95th percentile Doppler spread was about 1–13 Hz by frequency/season bin, while composite multipath spread was about 0.1–1.5 ms. The high Doppler at 14.36 MHz winter-day had 0.3-ms P95 composite delay; lower frequency bins could have larger delays. Some high-spread samples came from very few days. The study also reports occasional values >20 Hz and relates delay/shift excursions to convecting patches. For the NB subauroral path, P95 Doppler spreads were no more than 2 Hz while composite delays could exceed 4 ms. These examples falsify “delay and Doppler grow together as a single severity scalar.” They are samples from particular paths, not a global climatology or simultaneous worst-case guarantee.

Warrington et al. (2006) measured two northerly paths with multi-element arrays and found mode energy distributed over azimuth/elevation; a scalar tapped-delay model is inadequate if antenna-array spatial processing is being assessed. Their conclusion also emphasizes that available angular statistics were not enough to specify a universal scattering function. For a one-channel scalar receiver, defer angle-of-arrival implementation unless measured spatial/polarization inputs or antenna processing will be tested.

An independent long-haul auroral sounder study provides an unusually direct channel comparator. Nissen and Bello's 2003 measurements used a 500-W pseudo-noise probe, nominal 1-MHz bandwidth, 0.5-μs delay taps over a 2-ms window and up to 62.5 complex CIR samples/s on the 3100-km Sondrestrom–Bedford route from 14 March through 1 April 1992. Each statistical observation comprised 512 CIRs over approximately 8.2, 16.4 or 30.8 seconds, with faster sampling chosen when a chirp sounder indicated more disturbance. The authors removed records with significant contributions from multiple modes and retained about 100 channel probes. In that selected population, rms(2σ) Doppler spread was median 5 Hz, 10th/90th percentiles 1.75/13 Hz and max 17 Hz; rms(2σ) delay spread was median about 100 μs, 10th/90th 17/just over 400 μs and max 780 μs. A 15.5-MHz 1 April 07:34 UTC single-mode example had 7.5-Hz spread, ~100-μs delay spread and 6.6-Hz mean shift. Larger spread/shift and delay occurred during flare/active events, but these are short records and the selected single-mode statistic excludes precisely some multi-mode episodes. An equipment-filter convolution also correlates neighboring delay bins; their tap-correlation analysis supports uncorrelated scattering only down to roughly the filter autocorrelation scale (a few microseconds), not exactly independent adjacent measured samples. The article's distributions are marginals; use paired figure/raw values for any simultaneous-extreme statement.

### Disturbance, storm, absorption, and outage

“Geomagnetic storm” is not one channel law. Positive ionospheric storm effects can raise F-region critical frequency / usable frequency; negative effects can reduce MUF and persist after onset. Auroral electron precipitation increases D-region electron density/absorption and causes smaller/local MLT-structured events. Solar proton events increase polar D-region ionization over large regions and can last days (PCA). Solar flares' X-ray/EUV cause prompt lower-ionosphere/day-side shortwave fadeout (SWF), constrained to paths whose ionospheric path interacts with sunlit atmosphere. Storm-time irregularities/patches also change paths, shift, spread and directional structure. Their coincidence with absorption varies by event and geometry.

Bland et al. (2018) examined two September 2017 solar-proton events with SuperDARN routine noise and backscatter measurements. They observed near-total polar-radar backscatter loss for several days; attenuation reached 10 dB (north) / 14 dB (south) at 12 MHz. M-/X-class flares separately produced 2–4-h midlatitude attenuation enhancements. The measurement is radar/environment evidence; it establishes an observed absorption/outage case, not the probability of failure for a specific modem. Ghaly et al. (2024) show the value of measuring narrowband known terrestrial skywave signals simultaneously with CNA: a riometer is a relative cosmic-noise opacity meter, not a direct calibration of every oblique communication ray. Their review of literature reports D-region enhancement footprints ranging from tens to hundreds of km and event-to-event variability. A point gain-loss curve may stress a receiver but should not be claimed to represent the spatial intersection of an actual circuit without path-specific observations.

Gillies et al. (2026) add direct operation-level HF reception evidence on a route, not just a propagation proxy. Their Ottawa transmitter–Alert receiver circuit is over 3,000 km and runs south-to-north through subauroral, auroral and polar latitudes; modeling and received delays suggest at least two ionospheric hops. Routine operation sends CW plus a Barker-coded probe at six fixed carriers (5.38, 6.93, 8.10, 10.42, 11.11, 14.36 MHz), at 4, 8 or 24 probes per hour per frequency. When Alert decodes a Barker sequence, it records power, arrival azimuth/elevation, Doppler shift and propagation time; the expected but undecoded sequence is counted as lost. This is a stronger availability observable than sparse channel sounder snapshots, but it is not packet PER for the target modem. The occurrence analysis assumes continuous endpoint operation on days with data; the authors excluded July–August 2016 from the occurrence figure because near-zero receptions were interpreted as one endpoint not operating. The denominator therefore comes from the scheduled pulse table and a continuity inference, not independently audited uptime logs. Their expected-pulse loss is 62% overall and reception 38%. When the average 30-MHz absorption from all four selected riometers exceeds 2 dB, aggregate loss reaches about 80–90%, an 18–28 percentage-point increase over the pooled baseline. This still includes no usable reflecting mode and any inability to decode, not absorption alone.

The frequency plot uses a distinct statistic. For each carrier it normalizes (p(A,f)-p_{baseline}(f)) by the remaining possible increase (1-p_{baseline}(f)). Its 26–32% “additional loss” above 0.5 dB for most 5–11 MHz bands, about 19% at 14.36 MHz, and anomalous about 40% at 10.42 MHz are **fractions of possible additional loss**, not absolute conditional loss rates or percentage-point increases. If (q_f) is this normalized increment, (p(A,f)=p_{baseline}(f)+q_f[1-p_{baseline}(f)]); frequency-specific baseline probabilities differ because F-region reflection conditions and day/night availability differ. The 62% pooled value cannot substitute for those baselines. Site-conditioned normalized increments above 0.5 dB are 24–28% for three farther stations and 41% for Rankin Inlet, the closest; the article reports a 0.5 normalized increase around 1 dB at Rankin versus 1–2 dB at the more remote sites. All four used riometers are west of and at least ~900 km from the assumed link path; actual D-region pierce points vary with frequency/time and can be hundreds of kilometres north of those stations. The result makes riometer/path proximity and footprint overlap stronger predictors than a vertical absorption value alone.

Frequency and geometry are critical transfer constraints. In the 2017 Bland analysis, authors build quiet-day curves from beam- and frequency-band-specific SuperDARN background noise over August, excluding nonstandard range gates and atypical operating bands; August had at least 25 days per radar. Curves use 30-min UT-bin medians and smoothing; azimuth and terminator behavior matter, and long-lived August disturbance would bias the QDC. Bland’s within-study normalization to 12 and 30 MHz uses a nondeviative D-region A∝f⁻² assumption. Gillies et al. likewise give a theoretical 30-MHz vertical → 10-MHz oblique example: 0.5 dB vertical absorption could imply about 50 dB at a 10° multi-hop HF path if the same absorbing structure spans all its D-region crossings. The observed route does not show this as a deterministic outage: many expected probes are still detected above 0.5 dB, measured station-to-link separation is large, and Rankin predicts the link better than remote riometers. SuperDARN beam-integrated noise decrements and echo-loss masks also differ from received power of one known transmitter.

The inverse-square relation is conditional. An Appleton–Hartree simplification gives A∝f⁻² for nondeviative D-region absorption when collision/electron profiles and path length are fixed. Fiori et al. (2025) analyze a single 13–14 November 2012 KAIRA multi-frequency riometer event (10–80 MHz, filtered one-minute estimates). The empirical exponent varies from about −1.95 at A₃₀=0.2 dB to −1.40 at A₃₀=2.2 dB; their absorption-conditioned fit is event-specific and improves over fixed n=−2 for that event. Straight-line Appleton–Hartree calculations yielded slopes −1.99 to −1.84 (mean −1.91) without the same observed activity dependence, a retained model/data discrepancy. The empirical fit’s performance drops below 20 MHz, and the authors identify ambient electromagnetic noise as a major low-frequency riometer confound. Their vertical 10–80 MHz data do not calibrate 5–14 MHz oblique multi-hop links. Historical exponent estimates also vary (roughly −0.8 to −2.4 in cited multi-frequency HF links; −1.2 to −1.8 over an SPE energy range), with seasonal/event dependence. Do not multiply CNA by fixed powers to set path loss; use it as a conditional predictor only after local calibration and path-overlap validation, especially below 10 MHz where sensor noise and ray bending matter.

Outage should be represented in at least two distinct ways: (a) a multipath fade/null with energy still present in a recoverable/in-band channel; (b) a sustained path-loss/availability interval where all useful modes are below the demodulation threshold or no mode propagates. The former tests tracking/interleaving/diversity; the latter tests fallback, outage declaration, reacquisition and robust service accounting. A “no signal” simulation should retain noise/interference, advance channel time state and expose exactly when path loss crosses a receiver threshold. Do not create event incidence by combining independent stress knobs unless data supports their dependence.

### Polarization, amplitude and noise

The ionosphere is magnetized and dispersive. Its ordinary/extraordinary modes may differ in index, refraction, delay, phase/Doppler, attenuation and polarization. Faraday rotation depends on electron content and geomagnetic field; it may rotate a linearly polarized field, create an elliptical state, or alter received power for a single linearly polarized antenna. The F.1487 tap spectrum can include two separated magnetoionic components. ITU-R P.531 (trans-ionospheric scope, primarily satellite paths) describes TEC group delay/phase advance, Faraday rotation and scintillation, and is useful as physics context only: its transionospheric TEC/scintillation laws should not be inserted unmodified as a reflected 1–30 MHz circuit model. A receiver with one complex sample stream has already collapsed polarization through its antenna/front end; it cannot claim to simulate vector polarization diversity. Add a Jones/vector channel only if a dual-polarized front end and an observable diversity decision require it.

There is now a quantitative NVIS observation rather than only this generic magnetoionic description. Male et al. (2021) report 12 full days in December 2019 on a 5.4-MHz, 97-km Barcelona–Cambrils link. Cambrils receives two orthogonal inverted-V antennas through a ±90° phasing network, producing right- and left-hand circular channels that the authors associate with extraordinary/X and ordinary/O polarization in the northern hemisphere. Decoded-PN availability is time dependent: O-mode availability is only 30–40% during short sunrise/sunset “happy-hour” intervals when X is frequently received; both modes together yield 86% frame detection over 07–16 UTC. Mode-impulse responses are synchronized before cross-correlation, deliberately removing their bulk relative delay; a coefficient below .7 occurs about 40% of the time in the happy-hour windows. Among detected well-demodulated frames in the 07–16 UTC analysis window, reported mean delay spreads are O 0.33 ms and X 0.31 ms, with peaks 2.71 and 2.89 ms. This differs from a simple assumption that the O/X channels always have dramatically different delay or power: reported mean Eb/N0 differs by at most 2 dB, and selection combining improves Eb/N0 by up to 4 dB while equal-gain combining gives up to 3 dB and sometimes no improvement. The study is a direct communication link result, but not calibrated per-mode received field power: availability excludes undetected frames, and its low-cost SDR frequency instability (roughly −19.5 to −15 Hz) exceeds the expected ionospheric shift (up to ~4 Hz), so it explicitly does not estimate Doppler correctly. It establishes practical port/mode diversity and delay/selectivity evidence without a portable joint delay-power-Doppler law.

Amplitude laws are conditional. A single dominant ray with weak perturbations is not Rayleigh fading; a zero-mean proper complex Gaussian sum of many weak independent components yields Rayleigh envelope/Rician if a deterministic component is present. Watterson's model explicitly adopts stationary Gaussian tap gains as a useful measured approximation in its stated bandwidth/time conditions. Coherent discrete two-mode interference can give a non-Rayleigh distribution and regular frequency nulls. Severe high-latitude diffuse and time-varying angular structure can depart from stationarity and simple Gaussian assumptions. Report empirical CDF, fade depth/duration, level crossing rate, autocorrelation and outage fraction conditional on source SNR/threshold, with calibration floor and censoring. Do not infer amplitude law from Doppler-spread label alone.

HF noise is often external/environmental: lightning atmospheric noise, man-made receiver-site noise and other emitters; it varies by frequency, geography, season, local time, antenna and bandwidth. Interference may be an identifiable narrowband/structured signal or aggregate occupancy, not AWGN. ITU-R P.372 gives external noise figures / temperature distributions at a stated reference antenna; it excludes receiver internal noise and interference attributed to known services, and its received level depends on antenna/site and feeder. Keep received signal power, external noise density, receiver noise figure, occupied interference and receiver-input calibration in consistent planes/units. The companion noise branch owns detailed noise recommendations; this context is included because absorption and fading cannot be converted to SNR without it.

## Model equivalences and failure conditions

### P.533 link calculation vs physical channel

P.533 supplies frequency support, median field strength/power, path-mode contributions, noise and reliability estimates for circuit-planning decisions. Its time-frequency-window logic provides a receiver-useful functional abstraction and can suggest which delayed/shifted modes matter. It does not supply a unique time-varying waveform, phase, coherent cross-mode covariance, complex polarization, sample-by-sample fading or ADC response. Use it to select and describe candidate operating strata; keep the native continuous waveform renderer as the receiver execution path.

### F.1487 / Watterson subset vs current two-ray and Gaussian laws

F.1487/Watterson uses a tap-delay line. Each path/mode has its own complex Gaussian tap gain (and hence Rayleigh envelope if zero-mean), a declared mean-power split/attenuation, center shift and spectral width. It can use two Gaussian magnetoionic spectra on a tap when O/X components differ; if delay separation is large, represent those as distinct taps. The model assumes stationary Gaussian scatter within a test interval and explains how to compare modems over delay, Doppler and S/N surfaces. F.1487 says its model is valid in 3-kHz channels and may apply up to 12 kHz, always asking that front-end filters and gain control be considered.

The current fixed two-ray path alone is a deterministic/equal-power case: two delays, equal ray amplitudes, a fixed center separation and phase producing coherent notches. It cannot reproduce a Gaussian Doppler PSD merely by setting center separation. Separately, the low-level `gaussian_doppler_width_hz` and fixed-grid `random_doppler_width_hz` laws apply independent, zero-mean Gaussian gains to the two rays with a shared configured `B=2σ`, while `SpreadRay` supplies their equal mean powers, delay and center separation. With no additional common wander, OU/bounded stochastic-ray law, diurnal/moving-delay variation or changing attenuation during the analysis window, this already realizes a useful restricted two-tap Watterson/F.1487-equivalent subset when the target uses equal powers, two taps and the same Gaussian width. The match is limited: no arbitrary tap power/count, per-tap width/centroid, two-Gaussian O/X spectrum, mode birth/death, diffuse angular spread or occurrence distribution. A nonzero common wander or slow shared amplitude/absorption state makes a long record a mixture of local profiles rather than the same stationary independent-tap model.

The relations must not be confused:

- F.1487's `B=2σ` is a PSD width around each path's center, with Gaussian `σ`; 2σ encloses 68.27% of that one-dimensional Gaussian power. Its FWHM is 1.1774B, and the central 80%-power width is 1.2816B.
- A center-frequency difference between two taps adds deterministic differential phase rotation; it is not either tap's PSD width. One center can move commonly, while relative centers move differently.
- A path's absolute observed center shift also contains TX/RX oscillator offset/drift and other reference errors. Preserve calibration/reference-plane records to distinguish them.
- F.1487 Annex 3's high-latitude 7-ms/30-Hz row is a controlled equal-power two-tap stress value pair; the separately given occurrence indication says 5-ms delay and 25-Hz frequency spread are individually exceeded about 5% of the time. It does not say both are exceeded together 5% of the time.

### Time-frequency stationarity and WSSUS

The WSSUS assumption (wide-sense stationary uncorrelated scattering) is a working local model: over a specified analysis interval the second-order statistics are time invariant, and distinct excess delays are uncorrelated. It supports a scattering function `S(τ,ν)`, power-delay profile and Doppler spectrum. It is useful for stationary simulator profiles and for communicating receiver tolerances, not an assertion about a multi-hour HF session. Coherent modes can be correlated; two magnetoionic components, common plasma motion, deterministic specular paths, common shadowing/absorption and slowly migrating modes violate uncorrelated independent taps. Rapid bursts, changing state, and correlated ionospheric structures violate stationarity. A local WSSUS approximation should state its window, carrier/frequency, coordinate and event context, and report residuals/tests of stationarity.

A Gaussian PSD for each complex tap makes a proper Gaussian fading process and Rayleigh magnitude in the zero-mean case. Gaussianity is a useful comparison law, not a worst-case bound. A strong specular tap gives Rician/nonzero-mean behavior; two coherent deterministic taps give frequency selective fading with potentially deep stable nulls; multi-ray sums with unequal powers and changing geometry are not adequately summarized by a Rayleigh law; mixtures over multiple regimes can have heavy-tailed/nonstationary statistics. If a measured normalized PSD is strongly asymmetric/multimodal, the center-and-width pair is too small a descriptor. Preserve a measured scattering surface or event replay only when trustworthy captures exist and the receiver test needs it.

### Occurrence probability vs stress settings

Three evidence layers must stay separate:

1. **Controlled coverage:** F.1487 modem test profiles vary delay, Doppler and S/N independently to map a performance surface; this is a reproducible sensitivity experiment.
2. **Conditional climatological prediction:** P.533-style percentage/occurrence outputs are conditional on defined circuit geography, frequency, date/time/season and model family. The predicted median is not an event trace or guaranteed bound.
3. **Observed realization:** calibrated field sounder or known-signal record with event, path, instrument and censoring provenance.

A severe stress test belongs to layer 1 unless it is explicitly selected by an observed profile or calibrated conditional model. It may ask “does this receiver survive this tuple?” but not “this is a 95th percentile worst case.” For 2-D extremes, retain simultaneous paired samples from one time/path measurement. If only marginal exceedances are available, Fréchet bounds are the only general joint bounds: `max(0, pA+pB−1) ≤ p(A∩B) ≤ min(pA,pB)`. For two 5%-exceedance marginals, their joint exceedance could be anywhere from 0 to 5% absent dependence data.

## Measurements, estimators, provenance

### Calibration and reference planes

Each observation must retain: transmitted probe/modulation waveform and exact emission timing; antenna and feed reference plane; RF/IF conversion and TX/RX frequency references; gain/AGC state; receiver bandwidth and filters; sample rate/resolution; dynamic range/clip state; noise and interference floor; path-endpoint coordinates and antenna patterns/polarization; UTC/local-time and geomagnetic coordinates; frequency, season, solar/geomagnetic/event indices; instrument/site IDs and calibration; processing version; and whether each component is observed, modeled, censored or below a threshold. A sounder output calibrated at its receiver input is not directly the received RF power at the antenna; account for antenna gain, feeder loss, impedance, preselector, LNA/noise figure and analog/digital reference-plane changes.

No observed measurement is expected from the engineering owner in this assignment, so the report does not claim calibration. Before applying a field gain/noise floor, the owner must supply actual receiver/front-end ranges or a measured capture with a declared plane. Conditional sensitivity calculations should cover a range without pretending it is calibrated.

### Sounding and estimator conventions

A synchronized wideband probe can estimate the complex channel impulse response versus time by matched filtering/correlation. A common approach forms a delay-Doppler scattering estimate `|H(τ,ν)|²` across a declared coherent/integration window. Pulse compression sidelobes, receiver noise, interferers, estimator windowing, delay grid, Doppler resolution, aliasing and dynamic range affect estimated weak taps. Report the estimator and resolution, not just a phrase such as “delay spread.”

The literature's “spread” values have incompatible conventions:

- F.1487 Annex 3: two-mode **differential delay**; frequency spread is 2σ for the Gaussian tap spectrum.
- Stocker et al. (2013): composite multipath spread (CMPS) is first detected mode leading edge to last detected mode falling edge, corrected for probe width; modes >12 dB below strongest integrated power are excluded. “Doppler spread” is the narrowest spectral interval containing 80% of received power after correcting for base noise. SNR >=6 dB in 3 kHz and manual interferer rejection are selection conditions; their time-of-flight and Doppler estimates were on two-/three-minute snapshots with 0.5-Hz Doppler resolution. This is not RMS delay, RMS Doppler, or F.1487 2σ.
- Any new delay RMS calculation must name the weighting `P(τ)` and support threshold: `τ_rms = sqrt(ΣP_i(τ_i−τ̄)^2/ΣP_i)`. An absolute “last tap” depends on threshold and calibration floor. The excess delay of the latest significant mode is more reproducible if threshold and probe response are stated.
- Any percentile/outage must report the analysis window, selection/conditioned SNR, missing/failed soundings, number of independent intervals and the unit of independent trial. Adjacent short windows during one storm are not independent event replications.

Doppler can be estimated as phase slope or spectral power distribution, but oscillator error must be estimated/calibrated separately (frequency reference, path/clock drift). A single trace cannot separate systematic oscillator offset from common ionospheric shift without references/controls. Record absolute center and path-relative spread independently. Phase unwrap or a PLL estimate is not the path's full Doppler PSD.

For a communication receiver, report received complex signal and power in a named input plane, noise PSD/variance and measurement bandwidth, SNR/C/N0 and estimator, interference spectra/occupancy, clipping/AGC, correlation and packet/bit outcomes. Fade statistics should include mean/median and percentiles, CDF, fade depth/time below the receiver's actual threshold, fade-duration distribution, and outage fraction with exact threshold/reference. A physically valid signal-loss test cannot use future whole-capture power normalization because it erases absolute attenuation.

### Public calculation (performed)

`hf_calcs.py` in this chapter directory is a stdlib-only reproducible desk check; actual stdout is retained in `hf_calcs.txt`. It applies the F.1487 Gaussian PSD definition `B=2σ` to an ideal proper-complex stationary Gaussian gain. For `S(ν)∝exp(−ν²/(2σ²))`, normalized autocorrelation is `R(Δt)=exp(−2π²σ²Δt²)`, so the e-fold correlation time is `√2/(πB)`. With `B=30 Hz`, `σ=15 Hz`, FWHM is 35.32 Hz, central 80%-power width is 38.45 Hz, and ideal correlation e-fold time is 15.0 ms. With `B=0.5 Hz`, it is 0.900 s. These are analytical transformations, not an observed ionosphere or exact finite-FIR native runtime check; actual kernels/finite interpolation slightly alter the ideal covariance and should be measured from generated values if calibration matters.

The same script calculates free-space excess path `c·Δτ`: 7 ms corresponds to 2,098.5 km of excess ray length and 0.5 ms to 149.9 km. This is a *difference in path length*, not ionospheric reflection altitude, vertical layer separation, or direct horizontal ground distance. It is an order-of-geometry check against treating millisecond path separation as a few hundred meters of height.

## Implementation and evaluation decisions

1. **Keep exact Off baseline and current synthetic stresses.** Their value is matched receiver behavior and continuous timing/state. Label source controls vs realized path report. Do not silently change existing public hypotheses, chronology, waveform/source calendar or full receiver path.
2. **First expose a reproducible named profile through existing low-level controls.** Document the exact two-tap subset: equal mean powers, fixed excess delay, fixed center separation, shared per-ray Gaussian `B=2σ`, independent path seeds, explicit total/reference normalization, and no slow common state inside the fitted WSSUS window. Reuse the existing streaming delay history, gain process and source composition. Only add a bounded `N`-tap weighted table if measured CIRs repeatedly show additional resolved paths above a declared noise/probe threshold that change receiver outcomes. Such an extension should separately declare each path's delay, mean power/phase, center and `B`, tap correlation law, appearance/disappearance and total link gain; it must not normalize away the loss of a mode or path. Do not add 2–4 path arbitrariness as an assumed improvement over a working matched subset.
3. **Separate path loss/availability from fading.** Reuse existing low-level `PathEvolutionConfig`'s one signal-only attenuation interval for controlled, time-bounded path loss; it leaves the additive noise and channel/filter state active. It can compose with a low-level stream channel realization, but is not tied to PCA/SWF, contains only one interval, has no calibrated/reference-plane gain series, mode-specific mask or occurrence law, and reports only synthetic diagnostics. A zero gain interval tests receiver behavior through loss and return; it does not establish field outage probability. Add multi-event or per-mode attenuation series only when calibrated evidence makes them necessary. Expose power/outage threshold and denominator at receiver input; distinguish common attenuation, mode disappearance and coherent fading.
4. **Use conditional profile names, not automatic universal frequency/latitude laws yet.** Provide `quiet/midlatitude`, `low-latitude-scatter`, `high-latitude-quiet`, `high-latitude-disturbed`, `absorption/PCA`, and `SWF` as candidate cases with complete references/parameter provenance. P.1147 can provide a separate MF skywave field plan through 1.7 MHz; P.533 begins at 2 MHz, leaving a 1.7–2.0 MHz standards gap. Neither is a waveform law; see the separate HF reference calculation branch for validated planning examples. For HF skywave measurement profiles, retain the observed-source frequency, geometry, event, estimator, threshold and denominator. Keep regularistic stress dimensions orthogonal for sensitivity mapping. Only map a profile automatically from endpoints/time/solar indices when the provider's validated range and model output are available; no undocumented one-size numerical parameters.
5. **Profile combination should preserve causality and dependence.** Multiple physical factors can coexist, but only causal combinations should be represented: e.g., SPE+sunlit PCA, X-ray SWF+sunlit reflection paths, auroral precip+auroral absorption and local structured modes. Do not draw delay-tail, Doppler-spread, gain-loss and noise changes independently and call them one storm. If event-conditioned joint distribution is unknown, expose scenarios as named controlled combinations and avoid probabilistic claims.
6. **Receiver comparison should be paired and complete.** Against identical emitted bytes, seed roots, start/calendar, front-end settings, noise/interference and receiver run, compare Off, current two-ray, F.1487 restricted profile and a field replay if allowed. Report mode acquisition, SNR, estimates, outage time, packet completion and resource cost. Test channel estimation under wrong assumed covariance and mismatch. Include quiet/changed sequence, reacquisition/outage recovery, but separately label synthetic receiver outcomes from model fit/field validation.
7. **Escalate model complexity only on discriminating evidence.** Full magnetoionic/ray tracing is warranted if predicted mode path gains/delay/polarization must follow changing measured electron density; spatial/vector models if array, polarization or direction diversity is evaluated; non-WSSUS/event-specific replay if measured statistics reject stationarity; waveform-/front-end measurement if a link decision depends on dB-level performance. Favor a small, parameterized scalar table first, since it permits direct connection to F.1487 profiles and the production receiver with low operational complexity.

### Falsifiers and decision triggers

- A Gaussian-tap profile is insufficient if held-out calibrated soundings show multimodal/skewed spectra, persistent coherent modes, nonstationary PSD within the chosen block, or delay-dependent Doppler/power that changes outcomes relative to Gaussian model. First increase path/spectral descriptors; move to measured replay or physics model only if these explain the differences.
- A 2-path stress is insufficient if soundings resolve 3+ components above the declared floor and a three-path receiver response materially differs. Increase `N` only if the actual canonical workspace/CPU bound permits it.
- A scalar fading model is insufficient if simultaneous dual-pol measurements show polarization switching/nulls changing decode outcome and the intended hardware can receive independent polarizations. Add vector path only with those samples/hardware.
- Current high-latitude stress values are not a coverage guarantee; the standard's path-conditional percentile data refutes assuming one fixed distribution. Keep controlled extremes; gather local records and compare performance surface to observed tails.
- Any “storm profile” should be rejected if its event-conditioned absorption/path modes cannot be traced to the local source evidence, or if its event prediction claims exceed the measurement product's geography/frequency resolution.
