# EME source ledger

Search and access date: 2026-11-14. Web requests used the assigned `eme` meter recipe; all nested search/open/find items are counted. Search batches covered (1) 5.8 GHz / 5.76 GHz lunar radar and EME, (2) lunar radar scattering, radar equation, delay-Doppler, and libration, (3) 10 GHz EME measurements and polarization, (4) 5–6 GHz lunar brightness temperature / Moon noise, and (5) practical 5.76 GHz station reports and interference. Searches returned few peer-reviewed papers at the exact amateur 5.76 GHz frequency. The strongest exact-neighbor scientific echo measurement is at 7.209 GHz; there are operational 5.760 GHz records but not a comparable calibrated end-to-end dataset. The chapter does not claim an exhaustive systematic review or parity with unseen project research.

| Evans, J. V. and T. [NASA NTRS PDF](https://ntrs.nasa.gov/api/citations/20150020402/downloads/20150020402.pdf?attachment=true) | PDF lines 12–21: short-pulse and improved-power evidence rejects a uniformly bright rough disk; most echo concentrated on a small portion. It supports a central/leading component plus distributed tail rather than a frequency-specific 5.8GHz RCS. |

## Calculation provenance and verification

- Script: `link_budget.py` in this directory; Python standard library only, no install or project source edits.
- Source input values: Sensors paper Table 1 and observation details (2020 paper, 2019 observation); source sigma albedo and noise metric in its equations; standard constants `c` and Boltzmann `k`.
- Script output was observed by invoking `python3 studies/scientific-depth-2026-11-14/research/eme/link_budget.py` in the repository checkout. Output includes link-budget, sensitivity and geometry results summarized in `chapter.md`.
- It is a deterministic independent desk calculation; it does not access raw radar voltages, reproduce paper's surface mesh/DE436 pipeline, model antenna patterns, or qualify any product.
