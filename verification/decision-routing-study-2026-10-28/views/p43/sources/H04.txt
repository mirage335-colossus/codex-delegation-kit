   13 // A measured reference in the caller's absolute capture sample coordinates.
   14 // Phase is the observed tone phase at sample, with a known punctuation sign
   15 // removed after timing acquisition. It retains an unknown propagation/Tx phase.
   16 // sample is also the latest raw observation used for this publication: no
   17 // future input is hidden behind an earlier phase timestamp. Dwell timing is a
   18 // modulo-400 ms measurement, not an authenticated clock.
   19 // A metadata publication may propagate an older fitted phase to sample.
   20 // phase_observation_sample independently dates that actual fitted phase; its
   21 // known flag distinguishes an observation at sample zero from unknown origin.
   22 // Propagation and frequency fusion must not manufacture a new phase anchor.
   23 // Tone uncertainty combines an eight-standard-error local linearized LS term
   24 // (actual finite Gram covariance, estimated white-noise residual), numerical
   25 // floors and measured polynomial-model allowance. It is not a deterministic
   26 // bound for interference or future oscillator drift; callers retain fallback.
   27 // The configured process allowance separately encloses the finite raw-fit
   28 // change caused by a uniformly bounded Wiener phase path. It does not turn
   29 // the local AWGN linearization into a global likelihood/confidence interval.
   30 enum class FrequencyFit { unknown, local_polynomial, conditioned_polynomial, masked_tone_profile };
   31 // The former single-tone component fixtures retain their paired reversal.
   32 // Production optional metadata uses the separate auxiliary, whose240ms
   33 // reversal stays inverted until the zero-amplitude dwell boundary.
   34 enum class PunctuationFormat { paired_legacy, auxiliary_single };

   36 // One ACTUAL independently qualified phase-flip fit, not an extrapolated dwell
   37 // grid. Coordinates use Reference.sample_rate. The immutable last_sample is
   38 // also its actual raw evidence date; later tone/metadata publications may carry
   39 // this same observation but must not renew it. (generation,sample) identifies
   40 // the observation ONLY within one caller-owned provider/capture domain.
   41 // Generation is local to a Receiver instance; reconstruction requires a new
   42 // provider identity and explicit caller history reset. Receiver::reset changes
   43 // the local generation. An actual unknown-phase RF retune also resets its gauge.

   46     double fraction=0,uncertainty_samples=0;
   47     bool known=false;
