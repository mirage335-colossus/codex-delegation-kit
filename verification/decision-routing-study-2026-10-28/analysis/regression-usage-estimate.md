## Method and limits

A model request is one inference invocation; an agent turn can use several. Request ranges reflect assumed reads, tool interactions, discriminators, synthesis and independent reviews. Output includes an estimated allowance for reasoning, whose actual volume is unknown. New conversations are counted once, including a separate P06 consumer conversation at E2; P05 and P08 reuse existing conversations, and conditional workers reuse an appropriate domain conversation. P07/P08 and A5 already include coordinator work, so no extra administration assignment was added.

The shared context sensitivity is 16,000–48,000 input tokens per request, unmeasured and neither a floor nor a guarantee. Per request the low payload/history adds ceil(10% of the assigned excerpt bytes / 4) + 500 tokens; the high adds ceil(35% of bytes / 4) + 3,000. Four bytes per token and the excerpt fractions are approximations, and repeated history/tool content is counted per request. The source-byte union represents available excerpts, not observed reading. Output per request, including reasoning, is assumed Luna 500–1,800, Terra 600–2,000, and Sol/Astra 800–2,500 tokens.

The low endpoint treats 80% of the shared prefix as cached after the first request in each reused conversation; the first is cold. Cache is included within total input. The high endpoint assumes all input cold. Cache eligibility, lifetime and reuse are unknown, and the reserve assumes already-warm reused conversations. The common policy is approximately 85 KB / 11,500 words and actual role/tool harness may push the shared context outside this range. For each extra d common tokens per request, add d × requests to input. For low endpoint cost add d × [new conversations × input rate + (requests − new conversations) × (0.2 × input rate + 0.8 × cached rate)] / 1,000,000 if equally cacheable; for cold extra context or the high endpoint add d × requests × input rate / 1,000,000.

At user-supplied 2026-10-28 verified standard short-context rates, USD per million input / cached input / output: Luna $0.10 / $0.01 / $0.50, Terra $1 / $0.05 / $5, Sol $2 / $0.10 / $10, Astra $10 / $1 / $50. Cost = [(input − cached) × input rate + cached × cached rate + output × output rate] / 1,000,000. The rates were supplied for this estimation and were not independently retrieved here; actual tier and billing conditions may differ.

The separate user-reported, unitless weekly usage cost index is Terra = 1, Sol approximately 10, Astra approximately 20, Luna unknown. It is not an official rate and does not convert to API dollars or a share of weekly allowance. Subscription allowance and paid credits remain separate.
