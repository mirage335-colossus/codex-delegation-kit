# Result

On this environment, the measured import path has ample processing capacity
for the specified rate under the benchmark's assumptions. Three runs averaged
0.002847, 0.003011, and 0.003563 seconds per 1,000 records, leaving 0.997153,
0.996989, and 0.996437 seconds of each one-second arrival interval,
respectively. The slowest individual batch across those runs took 0.008902
seconds, leaving 0.991098 seconds. This is a quick capacity estimate, not a
proof of sustained operation in production.

`bench.py` now times `feed.import_lines` with 200 batches of 1,000 unique,
short valid JSON lines, including parsing, validation, SQLite inserts and each
batch commit. It uses a fresh file-backed database with default SQLite settings,
checks accepted and stored counts, and reports mean and maximum batch time and
margin. The 200,000 records represent 200 seconds of incoming data, but are
processed back-to-back, not in a real-time endurance run. Input generation,
setup, final count, acquisition, and other application work are excluded.

Commands run from this directory:

- `python3 -m unittest && python3 bench.py`: 2 tests passed; first benchmark
  mean 0.002847 s, margin 0.997153 s, max 0.003588 s, throughput 351,200/s.
- `df -T . && python3 --version && python3 -c 'import sqlite3; d=sqlite3.connect(":memory:"); print("SQLite", sqlite3.sqlite_version, "synchronous", d.execute("PRAGMA synchronous").fetchone()[0])'`:
  filesystem `tmpfs`, Python 3.13.5, SQLite 3.46.1, synchronous 2 (FULL).
- `python3 bench.py && python3 bench.py`: means 0.003011 and 0.003563 s,
  margins 0.996989 and 0.996437 s, maximum batch times 0.004045 and 0.008902 s,
  throughputs 332,094/s and 280,671/s.

The working directory is on tmpfs, so these numbers do not measure physical
persistent-storage commit latency. The benchmark also does not cover larger
or invalid records, different transaction sizes, network ingestion, queueing,
concurrent load, an established large database, or long-duration effects.
The intended storage, data and workload were not specified and are outside this
assignment; run the benchmark there with representative conditions before
making a production capacity claim. README documents the method and limits.
