# Result

Implemented an integer-sample, bounded-offset continuous-stream acquisition and decoding path, preserving the aligned check. Tests and benchmark load the current `cases.json` on each invocation; the receiver is given only the observation shape and known message length, not the true timing, frequency offset, or bits. The default offset search is -8 to +8 Hz in 1 Hz increments. The README explains assumptions, operation, measurement, and limitations.

Commands run in `/tmp/delegation-study/runs/r3`:

- `python3 -m unittest -v`: 4 tests passed, including bit recovery in all 3 current cases, reproducibility, nominal aligned decoding and input validation (0.093 s).
- `python3 receiver.py`: benchmarked repeated complete receives after preparation, for at least 0.5 s per case. Results from this run:

Corresponding wall-time slack was 99.0%, 99.1%, and 99.2%. The footprint sums measured Python input, prepared tables, and incremental traced peak workspace; respective workspace peaks were 216.4, 216.9, and 215.3 KiB. Reported Linux available memory was about 9861–9915 MiB at sampling, far above the footprint, but is not a process or container limit. `/sys/fs/cgroup/memory.max` and `/sys/fs/cgroup/memory.current` were unavailable here, so a container memory margin was not established.

The weak case decodes correctly despite a four-sample timing error. These results cover one deterministic noise realization per case, a fixed short observation and integer frequency/timing grid; they do not establish error rate, detection/false-alarm performance, fractional offset or drift tolerance, production throughput, latency, or behavior for other case shapes and loads. The receiver always produces a candidate even for pure noise. The CPU ceiling is a brief hot-cache sequential estimate and excludes synthesis and preparation. Memory numbers omit interpreter and non-Python overhead. Future altered cases are automatically included and may need a revised grid or receiver design if they do not recover. No installation or global configuration was changed.
