# Result

Implemented a complete, bounded acquisition/decision receiver in `receiver.py` and expanded the quick tests to read every current `cases.json` entry on each run. Added `benchmark.py` and updated `README.md`. The receiver is given observation geometry (including symbol count) but not true bits, start, or offset. It searches every fitting integer-sample start and a shared -8 to +8 Hz integer-Hz offset, using precomputed quadrature references and per-frequency prefix sums. It returns an estimate even in noise.

Commands and results, run in `/tmp/delegation-study/runs/r1` on Python 3.13.5, Linux x86_64:

- `python3 -m unittest -v`: 4 tests passed; current cases each recovered all bits, arrival within 16 samples and offset within 1 Hz; test runtime 0.093 s.
- `python3 benchmark.py --seconds 1`: synthesis and reusable preparation excluded from timing; each case repeatedly processed for at least one wall second; input includes leading/trailing noise. CPU ceiling is the reciprocal of measured CPU seconds/input second, an ideal single-core estimate, not demonstrated concurrent throughput. Traced memory is measured in a separate run and excludes interpreter/native baseline.

The weak case recovered all six bits but estimated the start four samples late. Each case uses one deterministic capture; these are not bit-error-rate or false-alarm statistics. The timing repeated that same capture 60–65 times per case. This is full finite-capture receive work, not continuous streaming or concurrent load; preparation, signal generation and I/O are excluded. Maximum frequency range/resolution and known sample rate, symbol dimensions and count are assumptions. Search cost changes with observation length, symbols, and grid, so results cannot be extrapolated to other cases without measuring them.

For this run Linux reported host `MemAvailable` 10,338,226,176 B, roughly 9,645–9,696 times the traced input + plan + peak-workspace estimate. This is only a shared-host snapshot and coarse comparison, not an allocation or channel limit: it omits baseline RSS, native memory, competing workloads and cgroup limits. Plans can be shared among identical geometries, but the ratio conservatively counts a plan per capture. No production capacity, false-positive, or parallel-scaling claims are supported. No remaining work is required for the bounded simulation; broader receiver validation would require additional captures and a separately specified operating envelope.
