## Remaining work

The user-requested suite is substantially unfinished. The highest-impact
prerequisite is DATA-only acquisition for Helper-free cases and integration of
acquisition and tracking into an actual message receiver. Map all settings from
the current list to canonical native source/channel (including FHSS, clock,
selective effects, loss and encryption) and fail closed for unmapped values;
connect source/channel to the receiver while separating public information from
simulation truth. Then predeclare small representative strata and independent
holdouts for success and for CPU/workspace estimates. Measure complete
post-preparation processing and represented baseband duration with actual thread
budgets and memory accounting, distinguish aggregate CPU seconds from wall time
at the machine's usable CPU ceiling, and report uncertainty. Implement exact
single-bit and literal `fox` message framing/calendar and a separately justified
>90% success target. A native plan's arbitrary duration and a true-atom
surrogate cannot stand in for correct-message probability. Quantify preparation
separately and establish whether longer lead is unavoidable. These items cannot
be inferred from the isolated fixed-geometry kernel harness or the early-exit
probe. Remove the retained build when it no longer serves this investigation.
