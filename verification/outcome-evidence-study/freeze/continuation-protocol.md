# Historical continuation protocol

After the original bounded historical runs and after the separately directed
feasibility witness established a possible native waveform-to-acquisition slice,
continue h1 (baseline) and h3 (v3) once each using the same neutral instruction
and a further approximately eight-minute work window. Neither actor is told the
witness method, its result, or the comparison rubric. The actors retain their
own prior context and work; this is a separate continuation phase, not a fresh
randomized trial. It does not erase the original partial results.

Score whether each independently starts and executes code or an experiment on
actual sampled receiver behavior, what it observes, whether the observation
supports its claims, and what remains untested. Also record prerequisites,
failures, unnecessary expansion, and limits. Realizing no useful additional
action is a valid observation. The time guidance is not a runtime-enforced
limit. Shared hardware and filesystem, differing prior work and model runtime
visibility limit inference; do not compare timings as capacity or claim causal
prompt effects. Keep each continuation's prompt, result and patch separate.

The identical continuation instruction sent to both actors was:

> Continue the original task in your same exercise directory with approximately eight more minutes of local work and relevant checks. Preserve the original result and failures; make further useful progress toward the requested outcome within your existing scope. Save a separate CONTINUATION.md with exact commands, results, limitations and remaining work. Do not access other exercise directories or use network or other agents.
